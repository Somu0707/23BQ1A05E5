# Campus Notification System

A Node.js backend project that demonstrates scheduling optimization, notification prioritization, logging middleware, and REST API integration.

## Features

### Vehicle Maintenance Scheduler

* Fetches depots and maintenance tasks from APIs
* Uses Dynamic Programming (0/1 Knapsack) to maximize maintenance impact
* Allocates tasks based on available mechanic hours

### Priority Inbox

* Fetches notifications from a protected API
* Assigns scores based on notification type and recency
* Displays the top priority notifications

### Logging Middleware

* Reusable logging utility
* Tracks application events and errors
* Designed for backend observability

## Tech Stack

* Node.js
* JavaScript
* Axios
* REST APIs
